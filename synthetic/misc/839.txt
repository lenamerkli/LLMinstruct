# Mimicking Google Chrome in Python HTTPS Requests

There are a few approaches ranging from simple to robust. The key insight: **just setting headers isn't enough** — sophisticated servers also check your **TLS fingerprint** (JA3/JA4), which differs between Python's `requests` and Chrome.

---

## 1. Quick & Simple: `requests` with Chrome Headers

The most straightforward approach. Just copy Chrome's request headers.

```python
import requests

headers = {
    "Host": "example.com",
    "Connection": "keep-alive",
    "sec-ch-ua": '"Chromium";v="134", "Not:A-Brand";v="24", "Google Chrome";v="134"',
    "sec-ch-ua-mobile": "?0",
    "sec-ch-ua-platform": '"Windows"',
    "Upgrade-Insecure-Requests": "1",
    "User-Agent": "Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/134.0.0.0 Safari/537.36",
    "Accept": "text/html,application/xhtml+xml,application/xml;q=0.9,image/avif,image/webp,image/apng,*/*;q=0.8,application/signed-exchange;v=b3;q=0.7",
    "Sec-Fetch-Site": "none",
    "Sec-Fetch-Mode": "navigate",
    "Sec-Fetch-User": "?1",
    "Sec-Fetch-Dest": "document",
    "Accept-Encoding": "gzip, deflate, br, zstd",
    "Accept-Language": "en-US,en;q=0.9",
    "Cookie": "session=...; ..."
}

response = requests.get("https://example.com", headers=headers, timeout=10)
print(response.text)
```

> ⚠️ **Limitation:** Python's TLS handshake has a different JA3 fingerprint than Chrome. Many anti-bot systems (Cloudflare, Akamai, DataDome) will still flag you.

## 2. Best Balance: `curl_cffi` (Browser TLS Impersonation)

This library uses `libcurl` under the hood and **mimics Chrome's TLS fingerprint**, HTTP/2 settings, and headers — making it nearly indistinguishable from a real browser.

### Install
```bash
pip install curl_cffi
```

### Usage
```python
from curl_cffi import requests

# Built-in impersonation presets
response = requests.get(
    "https://example.com",
    impersonate="chrome",   # automatically uses latest Chrome's fingerprint
    # or specify exactly: impersonate="chrome131"
)

print(response.status_code)
print(response.text)
```

### Available Presets
```python
# Common options:
impersonate="chrome"          # Latest stable Chrome
impersonate="chrome131"       # Specific version
impersonate="chrome_android"  # Mobile Chrome
impersonate="edge"            # Microsoft Edge
impersonate="safari"          # Safari
```

### More Options
```python
response = requests.get(
    "https://example.com",
    impersonate="chrome",
    headers={"Accept-Language": "en-GB,en;q=0.9"},
    cookies={"session": "abc123"},
    http_version="2",  # Force HTTP/2
    timeout=10
)
```

> ✅ **This is the recommended approach** for most scraping/automation use cases.

## 3. JavaScript-Heavy Sites: Real Browser Automation

If the site requires JavaScript execution (SPAs, React apps, etc.), you need a real browser:

### Option A: Playwright (Recommended)
```python
from playwright.sync_api import sync_playwright

with sync_playwright() as p:
    browser = p.chromium.launch(
        channel="chrome",  # uses your installed Chrome
        headless=True
    )
    context = browser.new_context(
        user_agent="Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 ...",
        viewport={"width": 1920, "height": 1080}
    )
    page = context.new_page()
    page.goto("https://example.com", wait_until="networkidle")
    content = page.content()
    browser.close()
```

### Option B: Selenium
```python
from selenium import webdriver
from selenium.webdriver.chrome.options import Options

options = Options()
# options.add_argument("--headless=new")  # optional
driver = webdriver.Chrome(options=options)
driver.get("https://example.com")
print(driver.page_source)
driver.quit()
```

## 💡 How to Get Chrome's Exact Current Headers

Open Chrome DevTools (`F12`) → **Network** tab → click any request → **Headers** section. Copy the request headers exactly. Headers change with each Chrome version, so keep them updated.

<details>
<summary><strong>Why TLS fingerprinting matters</strong></summary>

Every TLS client sends a unique "hello" packet with specific cipher suites, extensions, and their order. This creates a fingerprint (JA3/JA4 hash). Even with perfect headers, a Python `requests` call has a JA3 hash that any server can match against a database of known clients. Chrome's JA3 is unique and well-known — `curl_cffi` replicates it byte-for-byte.

</details>
