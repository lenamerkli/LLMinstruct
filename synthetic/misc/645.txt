# Combining Two PDF Files on Fedora Linux

There are several ways to combine PDFs on Fedora. Here are the most common methods:

## Method 1: Using `pdfunite` (Recommended - Simplest)

`pdfunite` is part of the `poppler-utils` package, which is usually pre-installed on Fedora.

**Install (if needed):**
```bash
sudo dnf install poppler-utils
```

**Combine PDFs:**
```bash
pdfunite file1.pdf file2.pdf merged.pdf
```

You can also combine more than two:
```bash
pdfunite file1.pdf file2.pdf file3.pdf merged.pdf
```

## Method 2: Using `qpdf`

**Install:**
```bash
sudo dnf install qpdf
```

**Combine PDFs:**
```bash
qpdf --empty --pages file1.pdf file2.pdf -- merged.pdf
```

This method is great if you want to extract specific pages too:
```bash
qpdf --empty --pages file1.pdf 1-3 file2.pdf 5-10 -- merged.pdf
```

## Method 3: Using Ghostscript

Ghostscript is typically already installed on Fedora.

```bash
gs -dBATCH -dNOPAUSE -q -sDEVICE=pdfwrite -sOutputFile=merged.pdf file1.pdf file2.pdf
```

## Method 4: GUI Application — PDF Arranger

If you prefer a graphical tool with drag-and-drop:

**Install:**
```bash
sudo dnf install pdfarranger
```

Then open it from your applications menu, drag in your PDFs, rearrange pages as needed, and export the combined file.

## Method 5: LibreOffice Draw

LibreOffice (pre-installed on Fedora Workstation) can open PDFs:

1. Open the first PDF in LibreOffice Draw
2. Drag the second PDF's pages into the sidebar
3. Export as PDF (`File → Export As → Export as PDF`)

---

**My recommendation:** For a quick command-line merge, use `pdfunite`. For visual reordering and merging, use `pdfarranger`.
