Hier ist eine strukturierte Musterlösung in \LaTeX-Formatierung, wie sie für mathematische oder statistische Prüfungen üblich ist:

```latex
\textbf{1. Definition der Hypothesen} \\
Es sei $p$ die Wahrscheinlichkeit, dass ein Patient durch das neue Medikament \textit{abc2} geheilt wird. Der Erfinder behauptet, dass die Heilungschance gestiegen ist. Daraus ergeben sich folgende Hypothesen:
\begin{itemize}
    \item Nullhypothese $H_0: p \leq 0{,}28$ (Das neue Medikament ist nicht wirksamer als das alte.)
    \item Alternativhypothese $H_1: p > 0{,}28$ (Das neue Medikament ist wirksamer.)
\end{itemize}
Da eine Erhöhung der Wahrscheinlichkeit überprüft werden soll, handelt es sich um einen \textbf{rechtsseitigen Hypothesentest}.

\vspace{0.5cm}

\textbf{2. Testgröße und Verteilung} \\
Die Testgröße $X$ beschreibt die Anzahl der geheilten Patienten. Unter der Annahme, dass die Nullhypothese gilt ($p = 0{,}28$), ist $X$ binomialverteilt mit den Parametern $n = 32$ (Anzahl der Patienten) und $p = 0{,}28$.
$$X \sim B(32; 0{,}28)$$

\vspace{0.5cm}

\textbf{3. Bestimmung des kritischen Bereichs (Ablehnungsbereichs)} \\
Das Signifikanzniveau ist $\alpha = 0{,}05$. Wir suchen die kleinste ganze Zahl $k$ (den kritischen Wert), ab der wir $H_0$ verwerfen. Es muss gelten:
$$P(X \geq k) \leq \alpha$$
$$1 - P(X \leq k-1) \leq 0{,}05$$
$$P(X \leq k-1) \geq 0{,}95$$

Mit Hilfe des Taschenrechners (kumulierte Binomialverteilung für $n=32, p=0{,}28$) prüfen wir die Werte:
\begin{align*}
    P(X \leq 12) &\approx 0{,}9169 \\
    P(X \leq 13) &\approx 0{,}9574
\end{align*}

Da $0{,}9574 \geq 0{,}95$ ist, folgt daraus:
$$k - 1 = 13 \implies k = 14$$

Der Ablehnungsbereich (kritische Bereich) ist somit $K = \{14, 15, \dots, 32\}$.
Der Annahmebereich ist $A = \{0, 1, \dots, 13\}$.

\vspace{0.5cm}

\textbf{4. Testentscheidung und Fazit} \\
In der Stichprobe zeigten 14 Patienten eine Verbesserung. Der beobachtete Wert ist somit $x = 14$.
Da $x = 14$ in den Ablehnungsbereich $K$ fällt ($14 \in K$), wird die Nullhypothese $H_0$ verworfen.

\textit{(Alternativer Weg über den p-Wert: Die Wahrscheinlichkeit, zufällig 14 oder mehr Heilungen zu beobachten, falls $H_0$ wahr wäre, beträgt $P(X \geq 14) = 1 - P(X \leq 13) \approx 1 - 0{,}9574 = 0{,}0426 = 4{,}26\,\%$. Da $4{,}26\,\% < 5\,\%$, wird $H_0$ verworfen.)}

\vspace{0.5cm}
\textbf{Antwortsatz:} \\
Die Nullhypothese wird auf dem Signifikanzniveau von 5\% verworfen. Die Daten liefern einen statistisch signifikanten Nachweis dafür, dass das neue Medikament \textit{abc2} wirksamer ist als das alte Medikament \textit{abc1}.
```

Hier ist ein Python-Skript, das die Standardbibliothek `scipy.stats` verwendet, um die exakten Wahrscheinlichkeiten der Binomialverteilung zu berechnen, den kritischen Bereich zu bestimmen und den p-Wert auszugeben.

### Voraussetzungen
Du benötigst das Paket `scipy`. Falls du es nicht hast, kannst du es im Terminal installieren:
```bash
pip install scipy
```

### Python Skript

```python
from scipy.stats import binom

# --- 1. Gegebene Parameter ---
n = 32                  # Stichprobenumfang (Anzahl Patienten)
p_null = 0.28           # Heilungswahrscheinlichkeit unter H0 (altes Medikament)
alpha = 0.05            # Signifikanzniveau (5%)
x_beobachtet = 14       # Anzahl der geheilten Patienten in der Stichprobe

print("="*40)
print(" HYPOTHESENTEST: BERECHNUNGEN")
print("="*40)
print(f"Parameter: n={n}, p0={p_null}, alpha={alpha}\n")

# --- 2. Bestimmung des kritischen Bereichs ---
# Wir suchen das kleinste k, für das gilt: P(X >= k) <= 0.05
# Das ist gleichbedeutend mit: P(X <= k-1) >= 0.95
ziel_wahrscheinlichkeit = 1 - alpha
k_kritisch = None

print("Suche nach dem kritischen Wert (Auszug der Verteilung):")
for i in range(n + 1):
    # binom.cdf(k, n, p) berechnet P(X <= k)
    prob_kumuliert = binom.cdf(i, n, p_null)

    # Zeige nur die relevanten Werte kurz vor und nach der 0.95-Grenze
    if 0.85 < prob_kumuliert < 0.99:
        print(f"  P(X <= {i:2d}) = {prob_kumuliert:.6f}")

    # Sobald die 95%-Marke überschritten wird, haben wir unser (k-1) gefunden
    if prob_kumuliert >= ziel_wahrscheinlichkeit and k_kritisch is None:
        k_kritisch = i + 1  # i entspricht hier k-1, also ist k = i + 1

print(f"\n-> Die Grenze von {ziel_wahrscheinlichkeit} wird bei P(X <= {k_kritisch-1}) überschritten.")
print(f"-> Der kritische Wert ist k = {k_kritisch}.")
print(f"-> Ablehnungsbereich K = {{{k_kritisch}, {k_kritisch+1}, ..., {n}}}\n")


# --- 3. Berechnung des p-Wertes für den beobachteten Wert ---
# p-Wert = P(X >= x_beobachtet) = 1 - P(X <= x_beobachtet - 1)
# Alternativ kann auch die Survival Function 'sf' genutzt werden: binom.sf(13, n, p)
p_wert = 1 - binom.cdf(x_beobachtet - 1, n, p_null)

print("="*40)
print(" TESTENTSCHEIDUNG")
print("="*40)
print(f"Beobachteter Wert: {x_beobachtet}")
print(f"Exakter p-Wert P(X >= {x_beobachtet}): {p_wert:.6f} (entspricht {p_wert*100:.2f}%)\n")

# --- Fazit ziehen ---
if x_beobachtet >= k_kritisch:
    print(f"FAZIT: Der Wert {x_beobachtet} liegt im Ablehnungsbereich (p-Wert < alpha).")
    print("Die Nullhypothese wird VERWORFEN.")
    print("Das neue Medikament ist auf dem 5%-Niveau signifikant wirksamer.")
else:
    print(f"FAZIT: Der Wert {x_beobachtet} liegt NICHT im Ablehnungsbereich (p-Wert >= alpha).")
    print("Die Nullhypothese wird NICHT VERWORFEN.")
    print("Es gibt keinen signifikanten Nachweis für eine höhere Wirksamkeit.")
```
