What happens when not all required ETS2 DLCs are installed when trying to use Promods?
§a§
Based on the ProMods forums and community discussions, here's what happens when you try to run ProMods without all the required map DLCs installed:

## The mod will not load properly

The ProMods team is explicit that this isn't supported: you can't run ProMods without the DLCs, because they use models and assets from the DLCs all over the map. This is a licensing/asset issue — because they are using SCS created map assets in their mod, which they are not allowed to distribute, their mod relies on the end user owning these DLCs.

## Specific symptoms you'll see in-game

1. **"Incompatible" mods in the Mod Manager** — Users report that when DLCs are missing, the mod components (Map, Media, Models, DLC Support, Definitions and Assets) show up marked as incompatible, with the message that "Dependencies: Some DLCs which are required by this mod are missing. Make sure you have all of them installed and activated".

2. **The mod simply won't load/activate** — As one moderator put it bluntly, the short answer is no, you can not use ProMods without the map-DLC (at least not the current version).

3. **Downgrade route (compatibility-breaking)** — There is technically an old workaround: you could downgrade your game all the way to ETS2 version 1.18 and play an old ProMods 1.91, though this is no longer possible via Steam, since Steam's oldest supported build has moved forward. This isn't practical for modern play.

4. **Regional interdependency** — Missing one DLC can break unrelated regions too, since assets are shared. For instance, without France they could not do Spain, and without Italy they could not do Greece.

## Why they require this

The current version's dependency list makes this explicit: the DLC Support package requires all eight ProMods packages to function properly, and 8 DLCs (Going East!, Scandinavia, Vive La France!, Italia, Beyond the Baltic Sea, Road to the Black Sea, Iberia and Western Balkans) are required to run this mod, while the Special Transport DLC is compatible but not required.

## Historical nuance

It's worth noting that not every DLC is required *immediately* upon release — ProMods sometimes ships an interim version that works with or without a brand-new DLC before folding in a hard requirement in a later update. For example, when West Balkans launched, ProMods v2.67 and v2.68 explicitly stated "This version will work *with or without* the Balkan West DLC enabled" before a subsequent version made it mandatory. Similarly with Iberia, several consecutive ProMods versions stated "Iberia is compatible but not required" before it eventually became a hard requirement.

**Bottom line:** if you're missing a required DLC, ProMods components will be flagged "incompatible" in the Mod Manager and the mod won't function — you either need to purchase the missing map DLC(s) or use an older ProMods/game version combo that predates that requirement.
