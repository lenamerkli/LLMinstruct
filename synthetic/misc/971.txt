### Refactored Code

```python
# 1. Define the prefix mapping as configuration data
COMPANY_PREFIX_MAP = {
    ('openai',): 'OpenAI',
    ('deepseek',): 'DeepSeek',
    ('ministral', 'mistral'): 'Mistral AI',  # Note: removed rogue underscore if unintended
    ('qwen', 'alibaba'): 'Alibaba',
    ('gemma', 'gemini', 'google'): 'Google',
    ('z-ai',): 'Z.ai',
    ('microsoft',): 'Microsoft',
    ('llama', 'meta'): 'Meta',
    ('moonshotai',): 'Moonshot AI',
    ('grok', 'x-ai'): 'X.com',
    ('anthropic',): 'Anthropic',
    ('nvidia',): 'NVIDIA',
    ('swiss-ai', 'apertus'): 'EPFL and ETH Zurich',
    ('ibm',): 'IBM',
    ('baidu',): 'Baidu',
    ('minimax',): 'MiniMax AI',
    ('poolside',): 'Poolside AI',
    ('cohere',): 'Cohere Inc.',
}

def get_company_from_model(model_name: str) -> str:
    """Cleans the model name and detects the creator/company."""
    model_name = model_name.lower()

    # Strip unwanted provider tags / suffixes
    for noise in ('openrouter/', 'publicai/', ':free'):
        model_name = model_name.replace(noise, '')

    if model_name.endswith('.gguf'):
        model_name = model_name.rsplit('-', 1)[0]

    # Find the matching company
    for prefixes, company in COMPANY_PREFIX_MAP.items():
        if model_name.startswith(prefixes):
            return company

    raise NotImplementedError(f"No company mapping found for model: '{model_name}'")


# Usage:
detected_company = get_company_from_model(llm.get_model())
```

---

### Key Improvements

1. **Tuple-based `.startswith()`**: Python's `str.startswith()` natively accepts a `tuple` of strings (e.g., `model.startswith(('gemma', 'gemini'))`). This eliminates the need for chaining `or` conditions.
2. **Separation of Data and Logic**: Adding, removing, or updating a model provider now only requires editing the `COMPANY_PREFIX_MAP` dictionary rather than touching the control flow.
3. **Encapsulation**: Wrapped inside a function `get_company_from_model()` for reusability and easier unit testing.
4. **Better Error Messaging**: `raise NotImplementedError(...)` now includes the unrecognized model name to make debugging easier.
