How can I replace ffmpeg-free with the full ffmpeg without uninstalling obs-studio?
§a§
Use the `dnf swap` command instead of `dnf remove`. This replaces one package with another in a single transaction, keeping your dependencies intact:

```bash
sudo dnf swap ffmpeg-free ffmpeg --allowerasing
```

"The dnf swap command removes one package and installs its replacement in a single transaction, preventing conflicts."

This removes ffmpeg-free and its libraries, then installs the full ffmpeg package with libx264, libx265, and other codec libraries. The `--allowerasing` flag allows DNF to remove conflicting packages like ffmpeg-free when installing the full FFmpeg build from RPM Fusion.

### Prerequisites

Since you're on Nobara, RPM Fusion should already be enabled. If not, enable it first:

```bash
sudo dnf install \
  https://mirrors.rpmfusion.org/free/fedora/rpmfusion-free-release-$(rpm -E %fedora).noarch.rpm \
  https://mirrors.rpmfusion.org/nonfree/fedora/rpmfusion-nonfree-release-$(rpm -E %fedora).noarch.rpm
```

### What happens

After the swap completes, the libx264 and libx265 encoders become available. OBS Studio and all its plugins will remain installed since the full `ffmpeg` package from RPM Fusion provides the same libraries they depend on.
