## 🖥️ What is Vast.ai?

Vast.ai, founded in 2018, operates as a cloud-based GPU marketplace connecting users seeking AI/ML compute with hosts who provide GPU resources via their own hardware by running Vast's hosting software. Put simply, Vast.ai is like the Airbnb of supercomputers — a marketplace where you can rent powerful GPUs from people and data centers across the world, billed by the hour.

---

## 🔧 How Does Renting a GPU Work?

Here's the step-by-step process:

1. **Create an account & add credits**
   You can start with as little as $5. Grab your API key from the console — no contracts, no sales calls.

2. **Search for a machine**
   There are various search options on the top and left control bars that allow you to filter for criteria like location, GPU type and count, various hardware specs, rental params, etc. The offer card shows the details of a machine available for rent, including specs, pricing, and the maximum rental duration.

3. **Choose a rental type**
   There are two rental modes: on‑demand, which runs continuously at a fixed price set by hosts; and interruptible, which uses a bidding system where the highest bid wins, but jobs can be paused if outbid or if higher-priority rentals begin.

4. **Select a Docker template**
   Before renting an instance, you'll need to select a template that defines your Docker image and connection method. Vast.ai provides Linux Docker instances, and one key step during setup is specifying what Linux Docker image to load.

5. **Configure your storage**
   The storage slider is both a search filter and a parameter input which determines the storage allocation size — it's important to size this correctly before creating any instance. When the instance is created, the disk size is set and cannot be modified. It is important to estimate how much disk you will need. The default disk size for an instance is 10GB.

6. **Rent & connect**
   Vast.ai will give you an SSH command — your key to remotely accessing the machine from your terminal. Startup time depends on the template and is usually under 5 minutes.

## 🔥 Running PyTorch

Vast.ai offers pre-built templates including PyTorch, CUDA, and TensorFlow.

- **Using the PyTorch template:** For LLM and deep learning experiments, it's easiest to start with the PyTorch template, which comes with CUDA, cuDNN, and many essential libraries pre-installed. This template runs inside an unprivileged Docker container.

- **Verifying your setup:** Once inside your instance (via SSH or Jupyter), you can verify PyTorch and GPU access directly in Python:
  ```python
  import torch
  print(f"PyTorch version: {torch.__version__}")
  print(f"CUDA available: {torch.cuda.is_available()}")
  print(f"GPU device: {torch.cuda.get_device_name(0)}")
  ```

- **Via CLI:** You can also launch a PyTorch instance directly from the command line. You can launch any Docker image on bare-metal GPUs, pass environment variables, expose ports, mount volumes, and SSH access is included.

- **Locking in CUDA versions:** You can lock in the exact CUDA and NVIDIA-driver versions your code needs.

## 💾 Does a CPU and Storage Come Along With It?

**Yes!** When you rent a GPU instance on Vast.ai, CPU and storage are included:

- **CPU:** Each instance comes with CPUs and RAM — though some servers share hardware, so it's possible to find instances on Vast.ai where CPU cores are already busy. You can filter by minimum vCPUs and RAM when searching.

- **Storage:** Providers charge for disk allocation even when the instance is stopped, so you only pay for what you allocate. You set the disk size before launching the instance.

- **Billing breakdown:** Pricing is broken into three components: active rental cost for the GPU (charged only when running), storage cost for allocated disk space (which applies even when the instance is stopped), and bandwidth costs for data transfer.

---

## ⏸️ Stopping vs. Destroying

- If you need a break, you can stop your instance in the Vast.ai console — you'll stop getting charged for GPU time, but your storage will still cost a bit.
- When you're truly finished with an instance, hit "Destroy" — this is the only way to fully stop all charges from accruing.

---

In summary, Vast.ai is a straightforward and affordable marketplace for GPU compute. You get a full Linux Docker environment with GPU, CPU, and storage all bundled together, and running PyTorch is as simple as selecting the pre-built PyTorch template at launch.
