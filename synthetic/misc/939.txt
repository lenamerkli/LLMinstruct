What is the maximal file size I can upload to my private cloud?
§a§
At the Nginx level, the maximum **entire request body** is:

```nginx
client_max_body_size 1500M;
```

That equals:

- **1,572,864,000 bytes**
- **1,500 MiB**
- approximately **1.465 GiB** or **1.573 GB**

The actual maximum file will be slightly smaller because multipart upload metadata is included in the request body. Your cloud application, PHP, or upstream server at `192.168.1.117:10084` may impose a lower limit, so the effective maximum is the lowest configured limit in the chain.
