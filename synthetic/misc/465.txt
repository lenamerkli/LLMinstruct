The error `ninemensmorris: ERROR (no such process)` occurs because while `supervisorctl reread` has successfully detected your new `ninemensmorris` process configuration, it hasn't been loaded into the main supervisor process list yet.

Here's a breakdown of the commands and the correct workflow to fix this:

### The Problem

1.  `supervisorctl reread`: This command scans for new and changed program configurations. Your output, `ninemensmorris: available`, correctly indicates that Supervisor has found your new process. However, at this stage, it's only "available" and not yet an active process that `supervisorctl` can manage.
2.  `supervisorctl start ninemensmorris`: When you run this command, Supervisor doesn't actually know about the `ninemensmorris` process yet because it hasn't been loaded. This is why you get the `ERROR (no such process)` message.

### The Solution

To fix this, you need to use the `supervisorctl update` command after `reread`. The `update` command loads any new or changed configurations into Supervisor's active process list.

Here is the correct sequence of commands:

```bash
root@servernode4:/home/server/documents/programmierprojekt_-ninemensmorris# supervisorctl reread
ninemensmorris: available
root@servernode4:/home/server/documents/programmierprojekt_-ninemensmorris# supervisorctl update
ninemensmorris: added process group
root@servernode4:/home/server/documents/programmierprojekt_-ninemensmorris# supervisorctl start ninemensmorris
ninemensmorris: started
```

**Alternatively**, you can use the `add` command to activate the specific process:

```bash
root@servernode4:/home/server/documents/programmierprojekt_-ninemensmorris# supervisorctl reread
ninemensmorris: available
root@servernode4:/home/server/documents/programmierprojekt_-ninemensmorris# supervisorctl add ninemensmorris

root@servernode4:/home/server/documents/programmierprojekt_-ninemensmorris# supervisorctl start ninemensmorris
ninemensmorris: started
```

In summary, `reread` tells Supervisor to check for changes, and `update` or `add` applies those changes. After that, you can successfully `start` your process.
