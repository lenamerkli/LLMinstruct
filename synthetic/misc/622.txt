# Überprüfung der Inhalte

Die Inhalte sind **korrekt**. Hier ist eine detaillierte Analyse:

## ✅ Winkel (Weg)
```
φ = b/r
```
Korrekt. Dies ist die Definition des Bogenmaßes.

## ✅ Winkelgeschwindigkeit
```
ω = Δφ/Δt = 2π/T = 2πf
```
Korrekt. Alle drei Ausdrücke sind äquivalent:
- Δφ/Δt: Definition
- 2π/T: Eine vollständige Rotation (2π rad) pro Periode T
- 2πf: Mit f = 1/T

## ✅ Zentripetalkraft
```
F_Z = mv²/r = mω²r
```
Korrekt. Beide Formeln sind äquivalent:
- Die erste Form verwendet die Bahngeschwindigkeit v
- Die zweite Form verwendet die Winkelgeschwindigkeit ω
- Mit v = ωr folgt: mv²/r = m(ωr)²/r = mω²r

## ✅ Zusatzinformation
Die Anmerkung, dass die Zentripetalkraft **keine Arbeit verrichtet**, ist korrekt und pädagogisch wertvoll. Sie steht immer senkrecht zur Geschwindigkeit, daher ist W = F·s·cos(90°) = 0.
