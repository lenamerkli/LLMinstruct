Certainly! Below is a LaTeX code using `pgfplots` to create a step plot similar to the one you provided. It includes colored markers at each step and a legend with colored labels.

```latex
\documentclass[tikz,border=3pt]{standalone}
\usepackage{pgfplots}
\usepackage{xcolor}
\pgfplotsset{compat=1.18}

\begin{document}
\begin{tikzpicture}
\begin{axis}[
    axis lines = middle,
    xlabel     = {Time},
    ylabel     = {$V$},
    xtick      = \empty, ytick=\empty,
    enlargelimits = 0.1,
    legend style = {
        at={(0.5,-0.18)}, anchor=north,
        legend columns=2, column sep=1em,
        draw=none, font=\small},
]
    %-----------------------------------------------------------------
    % 1) the staircase itself -> keep it OUT of the legend
    %-----------------------------------------------------------------
    \addplot[
        black, thick, const plot,
        forget plot                 % <-- this is the crucial part
    ] coordinates {
        (0,0) (1,0) (1,1) (2,1) (2,2)
        (3,2) (3,3) (4,3) (4,4)
    };

    %-----------------------------------------------------------------
    % 2) markers on the curve (also kept out of the legend)
    %-----------------------------------------------------------------
    \addplot[only marks, mark=asterisk*, mark size=3pt, blue,  forget plot] (0,0);
    \addplot[only marks, mark=*,          mark size=3pt, green!70!black, forget plot] (1,1);
    \addplot[only marks, mark=*,          mark size=3pt, yellow!80!black, forget plot] (2,2);
    \addplot[only marks, mark=*,          mark size=3pt, orange,          forget plot] (3,3);
    \addplot[only marks, mark=*,          mark size=3pt, red,             forget plot] (4,4);

    %-----------------------------------------------------------------
    % 3) the two legend entries you actually want
    %-----------------------------------------------------------------
    \addlegendimage{only marks, mark=asterisk*, mark size=3pt, blue}
    \addlegendentry{\textcolor{blue}{one}}

    \addlegendimage{only marks, mark=*, mark size=3pt, green!70!black}
    \addlegendentry{\textcolor{green!70!black}{green}}

\end{axis}
\end{tikzpicture}
\end{document}
```

### Explanation:
- The plot is a step function with horizontal and vertical segments.
- Colored markers are placed at the step points.
- The legend shows colored text matching the marker colors.
- Axes are labeled "Time" and "V" with arrows.
- The style mimics the hand-drawn style but is clean and clear.

You can compile this with `pdflatex` or any LaTeX editor that supports `pgfplots`. Let me know if you want it more hand-drawn style or with additional features!

You want a **Python script** that:

- Reads your data file (semicolon-separated, e.g. `data.txt`)
- Generates a LaTeX file (e.g. `plot.tex`) containing a `pgfplots` code block
- The LaTeX code should plot the step function with colored markers and a legend, as before

Below is a **complete Python script** that does this.
You can adjust the color/marker lists as needed.

---

```python
import pandas as pd

# Read the data
df = pd.read_csv('data.txt', sep=';', header=None, names=['time', 'value', 'label'])
df['time'] = df['time'].astype(float)
df['value'] = df['value'].astype(float)

# Colors and markers for LaTeX/pgfplots
latex_colors = [
    'blue', 'green!70!black', 'yellow!80!black', 'orange', 'red', 'purple', 'cyan', 'magenta'
]
latex_marks = [
    'asterisk*', '*', 'square*', 'triangle*', 'diamond*', 'star', 'pentagon*', 'oplus*'
]

# Prepare step coordinates for LaTeX
coords = []
for i in range(len(df)):
    t = df.loc[i, 'time']
    v = df.loc[i, 'value']
    coords.append(f"({t},{v})")
    if i < len(df) - 1:
        t_next = df.loc[i+1, 'time']
        coords.append(f"({t_next},{v})")

# Start LaTeX document
latex = r"""\documentclass{standalone}
\usepackage{pgfplots}
\usepackage{xcolor}
\pgfplotsset{compat=1.18}
\begin{document}
\begin{tikzpicture}
\begin{axis}[
    axis lines=middle,
    xlabel={Time},
    ylabel={V},
    xtick=\empty, ytick=\empty,
    enlargelimits=0.1,
    legend style={
        at={(0.5,-0.18)}, anchor=north,
        legend columns=2, column sep=1em,
        draw=none, font=\small
    },
]
"""

# Add the step plot (no legend)
latex += "    \\addplot[black, thick, const plot, forget plot] coordinates {\n"
latex += "        " + " ".join(coords) + "\n"
latex += "    };\n\n"

# Add markers (no legend)
for i, row in df.iterrows():
    color = latex_colors[i % len(latex_colors)]
    mark = latex_marks[i % len(latex_marks)]
    latex += f"    \\addplot[only marks, mark={mark}, mark size=3pt, {color}, forget plot] coordinates {{({row['time']},{row['value']})}};\n"

latex += "\n"

# Add legend entries
for i, row in df.iterrows():
    color = latex_colors[i % len(latex_colors)]
    mark = latex_marks[i % len(latex_marks)]
    label = row['label']
    latex += f"    \\addlegendimage{{only marks, mark={mark}, mark size=3pt, {color}}}\n"
    latex += f"    \\addlegendentry{{\\textcolor{{{color}}}{{{label}}}}}\n"

latex += r"""\end{axis}
\end{tikzpicture}
\end{document}
"""

# Write to file
with open('plot.tex', 'w') as f:
    f.write(latex)

print("LaTeX file 'plot.tex' generated.")
```

### **How to use:**
1. Save your data in `data.txt` (semicolon-separated, as in your example).
2. Run the script above (`python script.py`).
3. It will create `plot.tex` with the LaTeX code for your plot.
4. Compile `plot.tex` with `pdflatex` or Overleaf.
