What causes this and how can I fix it?
§a§
**The crash is caused by a mod compatibility issue between Copycats+ (com.copycatsplus.copycats.compat.SodiumCompat) and Sodium (me.jellysquid.mods.sodium.client.world.WorldSlice).**

Specifically:
- During chunk rebuilding/meshing (Sodium's RenderSectionManager), the Wires mod (de.mrjulsen.wires) is rendering wire segments.
- This triggers light emission calculation on a nearby MultiStateCopycatBlock (from Copycats+).
- Copycats+ tries to access the underlying world via `SodiumCompat.unwrapSodiumLevel()`, which directly reads the private `world` field from Sodium's internal `WorldSlice` class.
- Java's module system (enforced by Fabric's Knot classloader) blocks this access, throwing `IllegalAccessError`. This often happens due to a Sodium update making the field stricter (private/non-public) or version mismatch where Copycats+' Sodium compatibility code is outdated.

This chain involves:
- **Sodium**: Rendering engine.
- **Copycats+**: Copycat blocks providing light data.
- **Wires / Pantographs & Wires (PAW)**: Triggering the render via custom meshes and Sodium patches (e.g., SodiumCompatEvent, MeshAppenderRenderer).

### How to Fix It
1. **Update Copycats+** (primary fix):
   - Download the latest from [Modrinth](https://modrinth.com/mod/copycats) or [CurseForge](https://www.curseforge.com/minecraft/mods/copycats).
   - Recent versions (e.g., 2.1.0+, 3.0.x) include Sodium fixes like face culling and Embeddium compat. Check the [changelog](https://github.com/copycats-plus/copycats/blob/multiloader/CHANGELOG.md) for your MC version (likely 1.20.1–1.21.x based on stack trace).

2. **Update Sodium and dependencies**:
   - Get latest Sodium from [Modrinth](https://modrinth.com/mod/sodium).
   - Install/update **Indium** (required for Sodium + custom block rendering mods like Wires/PAW/Copycats): [Modrinth](https://modrinth.com/mod/indium).
   - Optional: Sodium Extra, Reese's Sodium Options for better config.
   - Match versions for your Minecraft/Fabric loader (check PrismLauncher mod list).

3. **Update related mods**:
   - **Wires**: [Modrinth](https://modrinth.com/mod/create-wires) – Update for Sodium mesh compat.
   - **Pantographs & Wires**: [Modrinth](https://modrinth.com/mod/create-pantographs-and-wires) – Has Sodium fixes in changelog.
   - Restart PrismLauncher, recreate instance if needed.

4. **Temporary workarounds**:
   - Remove/disable Copycats+ or Sodium (test by removing one at a time).
   - Avoid copycat blocks near wires if possible (rebuild chunks).
   - Downgrade Sodium to a version before the field access tightened (check Sodium commits if needed).

5. **If it persists**:
   - Share full logs/mods list on [Copycats+ GitHub issues](https://github.com/copycats-plus/copycats/issues) – No exact match found, so report it.
   - Test in a new world/profile.
   - Ensure Fabric API, Porting Lib are up-to-date (in stack trace).

This should resolve it – mod updates fix 90% of these Sodium compat crashes. Play safe!
