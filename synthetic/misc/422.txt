Here’s a clean LaTeX/pgfplots template that reproduces your “staircase over time” plot with colored markers on each plateau. Paste this into a file and compile with lualatex or pdflatex.

```latex
\documentclass[tikz,border=6pt]{standalone}
\usepackage{pgfplots}
\pgfplotsset{compat=1.18}

\begin{document}
\begin{tikzpicture}
\begin{axis}[
    width=12.5cm, height=7.5cm,
    axis lines=left,
    axis line style={->, line width=1pt},
    xmin=0, xmax=10,
    ymin=0, ymax=5.8,
    xtick=\empty, ytick=\empty,
    grid=both, grid style={gray!20},
    xlabel={Time}, ylabel={$V$},
    xlabel style={at={(axis description cs:0.98,0.02)}, anchor=south east},
    ylabel style={at={(axis description cs:0.02,0.98)}, anchor=north west},
    clip=false
]

% Step trace (edit coordinates to change plateau lengths and heights)
\addplot[
    black, thick,
    const plot % draws horizontal plateaus with vertical jumps
] coordinates {
    (0.2,1)  (2.0,1)
    (2.0,2)  (4.2,2)
    (4.2,3)  (6.4,3)
    (6.4,4)  (8.5,4)
    (8.5,5)  (9.3,5)
};

% Colored markers on each plateau (edit positions/colors/marks as needed)
\addplot+[only marks, mark=*, mark size=2.4pt, blue]           coordinates {(0.7,1)};
\addplot+[only marks, mark=*, mark size=2.4pt, ForestGreen]    coordinates {(2.6,2)};
\addplot+[only marks, mark=*, mark size=2.4pt, yellow!70!black]coordinates {(4.8,3)};
\addplot+[only marks, mark=*, mark size=2.4pt, orange]         coordinates {(6.9,4)};
\addplot+[only marks, mark=square*, mark size=3pt, magenta]    coordinates {(9.0,5)};

% "0" labels near the origin (optional)
\node[below left] at (axis cs:0,0) {$0$};
\end{axis}
\end{tikzpicture}
\end{document}
```

Notes and quick tweaks:
- Change the step timing/levels by editing the coordinate pairs in the const-plot block.
- Add or remove plateaus by adding/removing pairs following the pattern:
  (x_start, y_level) (x_end, y_level) then (x_end, next_y) ...
- Move markers by changing their coordinates; change shapes via mark=*, square*, triangle*, etc.
- If you want little “wiggles” at jumps, overlay a tiny TikZ path near a transition, for example:
  \draw[decorate, decoration={snake, amplitude=0.05cm, segment length=2mm}]
    (axis cs:4.2,2.9) -- (axis cs:4.2,3.1);
