Write a python script to extract this data.
§a§
Below is a **stand‑alone Python script** that will parse the HTML you posted (or any similar HTML that contains the accordion‑style bus‑line tables) and pull out the following information for every line:

| Field | Description |
|-------|-------------|
| `line` | The line number (e.g. “01”) |
| `direction` | “Hin” (inbound) or “Rück” (outbound) – taken from the URL segment `/Hin/` or `/Rueck/` |
| `route` | The human‑readable route description (e.g. “Obernau Dorf – Ebikon Fildern”) |
| `stops` | A list of stops. Each stop is a dict with `stop` (the stop name) and `pdf_url` (the link to the PDF timetable) |

The script works for the snippet you posted as well as for a full HTML page that contains many such accordions.
It writes the extracted data as **JSON** (easy to read) and also shows how you could export a CSV if you prefer.

## 2️⃣  The script (`extract_bus_lines.py`)

```python
#!/usr/bin/env python3
"""
extract_bus_lines.py

Parse an HTML page that contains the VBL bus‑line accordions and extract
line number, direction, route description and a list of stops with their
PDF timetable URLs.

Usage:
    python extract_bus_lines.py input.html          # read from a file
    python extract_bus_lines.py < input.html        # read from stdin
    python extract_bus_lines.py                      # same as above (stdin)

The script prints a JSON array with one entry per bus line.
"""

import sys
import json
import csv
from bs4 import BeautifulSoup


def extract_bus_lines(html_content: str):
    """
    Returns a list of dicts, one per bus line.
    """
    soup = BeautifulSoup(html_content, "html.parser")

    lines = []

    # Every bus line lives inside a div with class "accordeon-element"
    for acc in soup.select("div.accordeon-element"):
        # ------------------------------------------------------------------
        # 1️⃣  Extract line number and route description from the heading
        # ------------------------------------------------------------------
        heading = acc.select_one("div.heading h6.header")
        if not heading:
            continue  # skip if heading missing

        title = heading.get_text(strip=True).strip()

        # Expected format: "Linie 01 | Obernau Dorf - Ebikon Fildern"
        # Split on the first pipe “ | ”.
        parts = title.split(" | ", 1)
        if len(parts) < 2:
            continue

        line_text = parts[0].strip()   # e.g. "Linie 01"
        route_desc = parts[1].strip()  # e.g. "Obernau Dorf - Ebikon Fildern"

        # Pull out the numeric part – there may be extra spaces
        line_number = line_text.split()[-1] if line_text.split() else ""

        # ------------------------------------------------------------------
        # 2️⃣  Detect direction (Hin / Rück) from the first PDF link
        # ------------------------------------------------------------------
        direction = "unknown"
        table = acc.select_one("table.table")
        if table:
            first_a = table.select_one("a")
            if first_a:
                href = first_a.get("href", "")
                if "/Hin/" in href:
                    direction = "Hin"
                elif "/Rueck/" in href:
                    direction = "Rueck"

        # ------------------------------------------------------------------
        # 3️⃣  Extract all stops + PDF URLs from the table rows
        # ------------------------------------------------------------------
        stops = []
        if table:
            for row in table.select("tbody tr"):
                a = row.find("a")
                if not a:
                    continue
                stop_name = a.get_text(strip=True)
                pdf_url = a.get("href", "")
                stops.append({"stop": stop_name, "pdf_url": pdf_url})

        # ------------------------------------------------------------------
        # 4️⃣  Build the result entry
        # ------------------------------------------------------------------
        line_info = {
            "line": line_number,
            "direction": direction,
            "route": route_desc,
            "stops": stops,
        }
        lines.append(line_info)

    return lines


def write_json(data, out=sys.stdout):
    """Pretty‑print JSON to out."""
    json.dump(data, out, indent=2, ensure_ascii=False)
    out.write("\n")


def write_csv(data, filename):
    """
    Optional helper – writes a flat CSV where each row is one stop.
    Fields: line, direction, route, stop, pdf_url
    """
    with open(filename, "w", newline="", encoding="utf-8") as f:
        fieldnames = ["line", "direction", "route", "stop", "pdf_url"]
        writer = csv.DictWriter(f, fieldnames=fieldnames)
        writer.writeheader()

        for line in data:
            line_num = line["line"]
            direction = line["direction"]
            route = line["route"]
            for stop in line["stops"]:
                writer.writerow(
                    {
                        "line": line_num,
                        "direction": direction,
                        "route": route,
                        "stop": stop["stop"],
                        "pdf_url": stop["pdf_url"],
                    }
                )


def main():
    # ------------------------------------------------------------------
    # Read HTML – from file argument or from stdin
    # ------------------------------------------------------------------
    if len(sys.argv) > 1:
        # read a file
        with open(sys.argv[1], "r", encoding="utf-8") as f:
            html_content = f.read()
    else:
        # read stdin
        html_content = sys.stdin.read()

    bus_lines = extract_bus_lines(html_content)

    # Default output: JSON to stdout
    write_json(bus_lines)

    # Uncomment the following lines if you want a CSV file as well:
    # write_csv(bus_lines, "bus_lines.csv")


if __name__ == "__main__":
    main()
```

## 4️⃣  Customisation tips

| Need | How to adapt |
|------|--------------|
| **Different HTML layout** | Adjust the CSS selectors (`select_one("div.heading h6.header")` etc.) to match the structure of your page. |
| **Both “Hin” and “Rück” directions** | The script already detects direction automatically. If you have separate accordions for each direction they will appear as separate entries in the JSON. |
| **Export to other formats (XML, YAML, …)** | Replace the `write_json`/`write_csv` functions with any serializer you like (`xml.etree.ElementTree`, `yaml`, …). |
| **Download the PDFs** | After extracting the URLs you can loop over `stop["pdf_url"]` and use `urllib.request.urlretrieve` (or `requests.get` + `open`) to fetch them. |

*Copy the script above, install `beautifulsoup4`, run it on the HTML snippet (or a full page) and you’ll get clean JSON (or CSV) containing every bus line, its direction, route description and the list of stops with their timetable PDF URLs.*
