However, major version upgrades (especially those changing the Android base) are often released first to the **"Community"** (development) branch. The **"Official"** (stable) branch, which your phone is likely subscribed to, receives these updates weeks or months later after extensive testing , .
2.  **Current Status:** As of mid-June 2026, /e/OS 4.0 builds for the FairPhone 5 are available, but they are primarily listed under the **Community** channel. If your device is set to receive only "Official" stable updates, it will not see the /e/OS 4.0 update yet because the stable build for FP5 has likely not been pushed to the official OTA server for your specific configuration , .

### How to Update to /e/OS 4

You have two options: wait for the official stable release or manually install the Community build.

#### Option 1: Wait for the Official Stable Release (Recommended for most users)
If you prefer stability and want to keep your bootloader locked (if applicable) without manual intervention:
*   **Action:** Simply wait. The "Official" branch for FairPhone 5 is expected to receive the /e/OS 4.0 update in the coming weeks or months once Murena completes their testing cycle .
*   **Check:** You can monitor the official release notes on the Murena forum or website for the announcement of the "Official" FP5 build.

#### Option 2: Manually Install the Community Build (Advanced)
If you want /e/OS 4.0 immediately and are comfortable with manual installation, you can sideload the "Community" build.
*   **Warning:** This may require an unlocked bootloader. If you switch from an "Official" to a "Community" build, you might encounter signature mismatches. Community builds generally do not allow re-locking the bootloader , .
*   **Data Safety:** While an in-place upgrade is often possible, **always backup your data** before proceeding.

**Steps to Manually Update:**

1.  **Download the Build:**
    *   Go to the Murena OTA server for FairPhone 5 Community builds: `https://ota.ecloud.global/api/v1/FP5/community/` .
    *   Download the latest `.zip` file (e.g., `e-4.0-a16-...-community-FP5.zip` or similar, depending on the Android base version for v4.0). *Note: Ensure you download the OTA zip, not the IMG file if possible, or rename the IMG link by removing "IMG-" from the URL to get the flashable zip* .

2.  **Transfer to Phone:**
    *   Copy the downloaded `.zip` file to your phone's internal storage.

3.  **Local Update:**
    *   Go to **Settings** > **System** > **System updater**.
    *   Tap the **three-dot menu** (top right) and select **Local update** (or "Install from storage").
    *   Select the `.zip` file you copied.
    *   If you get a **signature mismatch** warning (common when switching branches), confirm that you want to install anyway .
    *   The phone will reboot and install the update.

4.  **Alternative: ADB Sideload (if Local Update fails):**
    *   Boot into **Recovery Mode** (Power off, then hold **Volume Down + Power**, select Recovery).
    *   Select **Apply update** > **ADB**.
    *   On your computer, run: `adb sideload <filename.zip>`.
