This is a well-known issue. The core error is:

```
ssl.SSLCertVerificationError: certificate verify failed: unable to get local issuer certificate
```

This means your system cannot verify the server's SSL certificate because it cannot find the issuer's certificate in the trusted certificate store. The bundled Python/Legendary inside Heroic can't locate your system's CA (Certificate Authority) certificates. Here's how to fix it, step by step:

---

## Fix 1: Update your system's CA certificates (most likely fix)

Your system's CA certificate bundle is likely missing or outdated.

**Debian/Ubuntu/Mint:**
```bash
sudo apt update
sudo apt install --reinstall ca-certificates
sudo update-ca-certificates
```

**Fedora/RHEL:**
```bash
sudo dnf reinstall ca-certificates
sudo update-ca-trust
```

**Arch/Manjaro/CachyOS:**
```bash
sudo pacman -S ca-certificates
sudo update-ca-trust
```

**openSUSE:**
```bash
sudo zypper install ca-certificates
sudo update-ca-certificates
```

After this, **restart Heroic** and try logging in again.

---

## Fix 2: Point Python's SSL to your system certificates

If Fix 1 didn't work, the bundled Legendary binary might not know *where* your CA bundle is. You can tell it explicitly by setting environment variables before launching Heroic:

```bash
export SSL_CERT_FILE=/etc/ssl/certs/ca-certificates.crt
export SSL_CERT_DIR=/etc/ssl/certs
heroic
```

> **Note:** The exact path to your CA bundle depends on your distro:
> - Debian/Ubuntu: `/etc/ssl/certs/ca-certificates.crt`
> - Fedora/RHEL/Arch: `/etc/pki/tls/certs/ca-bundle.crt`
> - openSUSE: `/etc/ssl/ca-bundle.pem`

To make this permanent, you can add the `export` lines to your `~/.bashrc` or create/edit Heroic's `.desktop` file to include them.

---

## Fix 3: Check your system clock

SSL verification will fail if your system clock is significantly wrong. Verify with:

```bash
timedatectl
```

If the time is wrong:
```bash
sudo timedatectl set-ntp true
```

---

## Fix 4: Update Heroic Games Launcher

The 2.20.1 hotfix for Heroic Games Launcher silences false-alarm error dialogs that were nothing more than harmless Python logs scaring users. Make sure you're on the latest version. The hotfix arrives through Heroic's built-in updater, so launching the program and clicking "Check for updates" is enough — once the download finishes, the launcher restarts automatically.

---

## Fix 5: Try the Flatpak version

If you installed Heroic via a native package (`.deb`, `.rpm`, AUR, etc.) and nothing above works, try the **Flatpak** version instead. Flatpak bundles its own certificate store and runtime, which avoids mismatches between the bundled Python and your system's SSL configuration:

```bash
flatpak install flathub com.heroicgameslauncher.hgl
flatpak run com.heroicgameslauncher.hgl
```

---

### Summary / TL;DR

The most common cause is a **missing or outdated CA certificate bundle** on your Linux system. Start with **Fix 1** (reinstalling `ca-certificates`), then try **Fix 2** (setting `SSL_CERT_FILE`). If those fail, verify your clock (**Fix 3**), update Heroic (**Fix 4**), or switch to the Flatpak (**Fix 5**).
