==Crushing Speed==
There are 4 variables that effect the processing speed of the Crushing Wheel: RPM, stack size, recipe duration, input delay. The recipe duration is a number assigned to each recipe as shown in the following table below. The input delay is the number of ticks it takes for an item to be inserted into the crushing wheels, The input delay is set by the component inserting the items and is 1 for any funnel, 3 for any chute, and 27 if thrown directly to the crushing wheel. Be aware that the use of belts to feed the funnel will add more delay.

=== Crushing Speed Formula ===
To calculate the exact number of game ticks it take to process an input, use this formula:

<math>\text{processing time (ticks per stack size)} = \left\lfloor \frac{\text{recipe duration in ticks} - 20}{\max \left(0.25, \min \left( \frac{\frac{\text{RPM}} \text{50} \times 4}{\log_2(\text{stack size})}, 20 \right)\right) } \right\rfloor + 1 + \text{input delay} </math>

How many sets of crushing wheels do I need to crush 14'680.64 tuff per minute with 256 RPM and 64 Stack size?
§a§
To find out how many sets of crushing wheels you need, we first have to calculate the processing speed of a single set of crushing wheels using the formula provided.

Here are the variables we will use:
* **Item:** Tuff
* **Recipe Duration:** 350 ticks (found in the 350 column of the table)
* **RPM:** 256
* **Stack Size:** 64
* **Input Delay:** 1 tick (assuming you use a funnel, which is the most optimal/fastest method).

### Step 1: Calculate the denominator
First, we solve the core equation in the denominator:
* $\frac{\text{RPM}}{50} \times 4 = \frac{256}{50} \times 4 = 5.12 \times 4 = 20.48$
* $\log_2(\text{stack size}) = \log_2(64) = 6$
* $\frac{20.48}{6} \approx 3.4133$

Now apply the min/max limits:
* $\min(3.4133, 20) = 3.4133$
* $\max(0.25, 3.4133) = 3.4133$

### Step 2: Calculate the ticks per stack
Now we plug the denominator and the recipe duration (350) back into the full formula:
* $\text{Numerator} = 350 - 20 = 330$
* $\frac{330}{3.4133} = 96.6796875$

Next, apply the floor function (round down to the nearest whole number):
* $\lfloor 96.6796875 \rfloor = 96$

Finally, add the base tick and your input delay (using a funnel = 1 tick):
* $\text{Processing time} = 96 + 1 + 1 = \mathbf{98 \text{ ticks per stack}}$

### Step 3: Calculate items per minute per machine
Minecraft runs at 20 game ticks per second, which means there are **1,200 ticks in a minute**.
* $\text{Stacks per minute} = \frac{1200 \text{ ticks}}{98 \text{ ticks per stack}} \approx 12.2449 \text{ stacks/min}$
* $\text{Items per minute} = 12.2449 \text{ stacks} \times 64 \text{ items} \approx \mathbf{783.67 \text{ items/min}}$

### Step 4: Calculate the number of Crushing Wheels needed
To find the required number of machines, divide your target rate by the rate of a single machine:
* $\frac{14,680.64 \text{ target items/min}}{783.67 \text{ items/min per machine}} \approx \mathbf{18.73 \text{ machines}}$

Since you cannot build a fraction of a machine, you round up to the nearest whole number.

### Conclusion
You will need **19 sets of crushing wheels** to meet your goal (assuming you feed them using funnels).

***Note:** If you choose to feed the machines using **chutes** instead, the input delay becomes 3, increasing the processing time to 100 ticks per stack. This drops the machine's speed to exactly 768 items/min, which would mean $14,680.64 \div 768 = 19.11$. In that specific scenario, you would be forced to build **20 sets**.*
