### Note on usage with OpenAI SDK:
If you are using the official `openai` npm package, this structure is directly compatible with the `ChatCompletionTool` type. You can pass it directly into your chat completions call like this:

```typescript
import OpenAI from "openai";

const openai = new OpenAI();

const response = await openai.chat.completions.create({
  model: "gpt-6-astra",
  messages: [{ role: "user", content: "List the files in the home directory" }],
  tools: TOOLS, // Passed directly here
  tool_choice: "auto"
});
```
