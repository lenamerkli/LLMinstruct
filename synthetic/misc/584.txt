§u§
I have an Angular frontend and flask python backend. How can I implement user uploads?
§a§
Implementing file uploads between an Angular frontend and a Flask backend involves using `multipart/form-data` on the Angular side to send the file, and Flask's built-in `request.files` to receive and save it.

Here is a complete, step-by-step guide to implementing this securely and effectively.

---

### Part 1: Flask Backend (Python)

First, set up your Flask application to accept file uploads.

**1. Install dependencies**
If you haven't already, install Flask and Flask-CORS (to prevent Cross-Origin errors when Angular talks to Flask).
```bash
pip install Flask flask-cors
```

**2. Create `app.py`**
```python
import os
from flask import Flask, request, jsonify
from flask_cors import CORS
from werkzeug.utils import secure_filename

app = Flask(__name__)

# Enable CORS for Angular frontend (adjust origin in production)
CORS(app, origins=["http://localhost:4200"])

# Configuration
UPLOAD_FOLDER = 'uploads'
ALLOWED_EXTENSIONS = {'txt', 'pdf', 'png', 'jpg', 'jpeg', 'gif', 'docx'}
app.config['UPLOAD_FOLDER'] = UPLOAD_FOLDER
app.config['MAX_CONTENT_LENGTH'] = 16 * 1024 * 1024  # 16 MB limit

# Ensure upload folder exists
os.makedirs(UPLOAD_FOLDER, exist_ok=True)

def allowed_file(filename):
    return '.' in filename and \
           filename.rsplit('.', 1)[1].lower() in ALLOWED_EXTENSIONS

@app.route('/api/upload', methods=['POST'])
def upload_file():
    # Check if the post request has the file part
    if 'file' not in request.files:
        return jsonify({"error": "No file part in the request"}), 400

    file = request.files['file']

    # If the user does not select a file, the browser submits an empty file without a filename
    if file.filename == '':
        return jsonify({"error": "No file selected"}), 400

    if file and allowed_file(file.filename):
        # secure_filename prevents directory traversal attacks
        filename = secure_filename(file.filename)
        filepath = os.path.join(app.config['UPLOAD_FOLDER'], filename)

        # Save the file
        file.save(filepath)

        return jsonify({
            "message": "File successfully uploaded",
            "filename": filename
        }), 200
    else:
        return jsonify({"error": "File type not allowed"}), 400

if __name__ == '__main__':
    app.run(debug=True, port=5000)
```

### Part 2: Angular Frontend

**1. Generate a Service and Component**
```bash
ng generate service services/upload
ng generate components/upload
```

**2. Create the Upload Service (`upload.service.ts`)**
We use `FormData` to package the file into `multipart/form-data` format.

```typescript
import { Injectable } from '@angular/core';
import { HttpClient, HttpEventType, HttpEvent } from '@angular/common/http';
import { Observable } from 'rxjs';

@Injectable({
  providedIn: 'root'
})
export class UploadService {
  private apiUrl = 'http://localhost:5000/api/upload';

  constructor(private http: HttpClient) { }

  uploadFile(file: File): Observable<HttpEvent<any>> {
    const formData: FormData = new FormData();
    formData.append('file', file, file.name);

    // Note: reportProgress and observe: 'events' allow us to track upload progress
    return this.http.post(this.apiUrl, formData, {
      reportProgress: true,
      observe: 'events'
    });
  }
}
```

**3. Create the Component Logic (`upload.component.ts`)**
```typescript
import { Component } from '@angular/core';
import { UploadService } from '../services/upload.service';
import { HttpEventType, HttpResponse } from '@angular/common/http';

@Component({
  selector: 'app-upload',
  templateUrl: './upload.component.html',
  styleUrls: ['./upload.component.css']
})
export class UploadComponent {
  selectedFile: File | null = null;
  uploadProgress: number = 0;
  message: string = '';
  isError: boolean = false;

  constructor(private uploadService: UploadService) {}

  // Triggered when user selects a file
  onFileSelected(event: any): void {
    this.selectedFile = event.target.files[0] ?? null;
    this.message = '';
    this.uploadProgress = 0;
  }

  // Triggered when user clicks upload
  onUpload(): void {
    if (!this.selectedFile) {
      this.message = 'Please select a file first!';
      this.isError = true;
      return;
    }

    this.uploadService.uploadFile(this.selectedFile).subscribe({
      next: (event) => {
        if (event.type === HttpEventType.UploadProgress) {
          // Calculate the upload percentage
          this.uploadProgress = Math.round(100 * (event.loaded / (event.total || 1)));
        } else if (event instanceof HttpResponse) {
          this.message = 'Upload successful!';
          this.isError = false;
          this.selectedFile = null; // Reset file
        }
      },
      error: (err) => {
        this.message = err.error?.error || 'Upload failed!';
        this.isError = true;
        this.uploadProgress = 0;
      }
    });
  }
}
```

**4. Create the Component Template (`upload.component.html`)**
```html
<div class="upload-container">
  <h2>Upload a File</h2>

  <input type="file" (change)="onFileSelected($event)" />

  <button (click)="onUpload()" [disabled]="!selectedFile">
    Upload
  </button>

  <!-- Progress Bar -->
  <div *ngIf="uploadProgress > 0 && uploadProgress <= 100" class="progress-bar">
    <div class="progress" [style.width.%]="uploadProgress">
      {{ uploadProgress }}%
    </div>
  </div>

  <!-- Message -->
  <p *ngIf="message" [style.color]="isError ? 'red' : 'green'">
    {{ message }}
  </p>
</div>
```

### Important Best Practices for Production

1. **Serving Static Files:** In development, Flask saves files to the `uploads/` folder. In production, it's highly recommended to save files to a cloud storage bucket (like AWS S3, Google Cloud Storage, or Azure Blob) rather than the Flask server's local disk.
2. **Don't Trust Filenames:** Always use `secure_filename()` from Werkzeug. A malicious user could name their file `../../../etc/passwd` to overwrite system files.
3. **Database Tracking:** Usually, after `file.save()`, you will want to create a database record (using SQLAlchemy, for example) that stores the filename, upload date, and the user who uploaded it, so you can retrieve it later.
4. **CORS Configuration:** In the Flask code, `CORS(app, origins=["http://localhost:4200"])` is fine for dev. In production, change this to your actual Angular domain (e.g., `https://myapp.com`).
5. **File Size Limits:** Flask's `MAX_CONTENT_LENGTH` is set to 16MB here. If you expect larger files (videos, large datasets), you will need to increase this, and potentially configure your reverse proxy (Nginx/Apache) to allow larger request bodies as well.
