This is a personal first hand account of the poster's lived experience. There is exactly one potential point of concern which requires explicit explanation:

The poster uses a transphobic slur exactly one time. They are not using this slur to insult, attack or degrade anyone. They are repeating, verbatim, the exact insult that a stranger used against them, which they are describing.

Under rule 6 of this forum there is an explicit exception written into the rules:

### Moderator note
A very standard principle of moderation applied almost universally is that there is a material difference between:
