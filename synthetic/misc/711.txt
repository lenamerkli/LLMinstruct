§a§
I searched Hugging Face for models that can help turn a phone photo of a printed document into something closer to a clean scanner output. The best matches I found are mostly **pipeline components** rather than one perfect all-in-one model.

**Best models I found**

- `ordaktaktak/Document-Scanner` — this is the most directly relevant model for the **crop/extract** step. Its card describes a U-Net-like scene-document detector; the usage shows `ScanView` to detect the document area, `ExtractPaper` to extract the page, and `EnhacePaper` to enhance the extracted paper.

- `PaddlePaddle/UVDoc` — this is a dedicated **document unwarping / perspective-correction** model. The model card says it corrects document distortion, inclination, perspective deformation, and similar issues, and Hugging Face’s UVDoc docs show `post_process_document_rectification(...)` for rectifying photographed documents.

- `fredcallagan/uvdoc-grid-onnx` — this is the strongest HF option I found for **high-quality unwarping** if you care about preserving native resolution. Its card says it outputs a coordinate grid instead of a low-resolution image, so you can remap the original image with `cv2.remap()`, which is better for scanner-like sharpness.

- `DaVinciCode/doctra-docres-main` + `DaVinciCode/doctra-docres-mbd` — this is the closest thing I found to a **single restoration model** for the cleanup stage. The main weights cover dewarping, deshadowing, appearance enhancement, deblurring, and binarization, while the MBD weights generate document masks/background priors used by the DocRes pipeline. A rehosted `presencesw/DocRes` repo is also on Hugging Face.

- `SBB/sbb_binarization` — best if you want a **black-and-white scanner look** rather than a cleaned-up color photo. The model card describes it as a pixelwise document binarization model for improving OCR by separating text from degraded backgrounds, and it reports strong competition results on DIBCO-style benchmarks.

- `ShuhaoGuan/prep-ocr-resshift-deblur` — useful add-on if your document photos are **blurry**. Its card says it is a PreP-OCR model fine-tuned for document image deblurring.

- `Jwalit/document-moire-detector` — not a restoration model, but a useful **quality-check** model if phone-camera captures produce moiré artifacts. Its card says it classifies document images as `clean` or `moire`.

**What I’d recommend**

- For a **clean color “like a scanner” result**: `Document-Scanner` → `uvdoc-grid-onnx` → `doctra-docres-main`. This combines page extraction, geometric correction, and cleanup/restoration. That recommendation is my inference from the model cards, which split those responsibilities across separate models.

- For a **classic OCR-ready monochrome scan**: `Document-Scanner` → `PaddlePaddle/UVDoc` → `SBB/sbb_binarization`.

- If the input is **motion-blurred**, add `prep-ocr-resshift-deblur` before or after DocRes, depending on where the blur is worst.

**If you want the closest thing to an integrated Hugging Face-backed pipeline**, `PaddlePaddle/UVDoc` is also exposed through PaddleOCR, and the Hugging Face model page shows it can be enabled inside `PPStructureV3`, which includes layout detection and an optional document-image preprocessing sub-pipeline.

§a§
Below is a practical **one-file CLI** that does exactly the pipeline you asked for:

1. **optional page crop** from the camera photo,
2. **UVDoc** for **rectification / dewarping**,
3. **DocRes** for **deshadowing**,
4. **DocRes** again for **appearance enhancement / illumination cleanup**,
5. a mild final tone normalization to make the page look more like a clean color scan.

I picked UVDoc because Hugging Face’s official Transformers docs show direct **PyTorch** inference with `AutoImageProcessor`/`AutoModel` plus `post_process_document_rectification(...)`, and I picked DocRes because the official repo and HF weights describe **deshadowing** and **appearance enhancement** as supported document restoration tasks.

Because you already have **CUDA-enabled PyTorch**, I would **not** install DocRes’s pinned torch requirements over your environment; the official DocRes requirements pin `torch==1.11.0+cu113` and `torchvision==0.12.0+cu113`. So the setup below installs only the extra Python packages you need and keeps your existing torch install intact.

```python
#!/usr/bin/env python3
import argparse
import sys
from pathlib import Path

import cv2
import numpy as np
import torch
from PIL import Image, ImageOps
from huggingface_hub import hf_hub_download
from transformers import AutoImageProcessor, AutoModel

UVDOC_MODEL_ID = "PaddlePaddle/UVDoc_safetensors"
DOCRES_REPO_ID = "DaVinciCode/doctra-docres-main"
DOCRES_FILENAME = "docres.pkl"

SCRIPT_DIR = Path(__file__).resolve().parent
DOCRES_ROOT = SCRIPT_DIR / "third_party" / "DocRes"

if not (DOCRES_ROOT / "models" / "restormer_arch.py").exists():
    raise SystemExit(
        "Missing DocRes source.\n"
        "Run:\n"
        "  mkdir -p third_party\n"
        "  git clone --depth=1 https://github.com/ZZZHANG-jx/DocRes third_party/DocRes"
    )

sys.path.insert(0, str(DOCRES_ROOT))
from models import restormer_arch  # noqa: E402


def read_image_bgr(path: str) -> np.ndarray:
    pil = Image.open(path).convert("RGB")
    pil = ImageOps.exif_transpose(pil)
    rgb = np.array(pil)
    return cv2.cvtColor(rgb, cv2.COLOR_RGB2BGR)


def save_image(path: Path, image: np.ndarray) -> None:
    path.parent.mkdir(parents=True, exist_ok=True)
    ext = path.suffix.lower()
    if ext in {".jpg", ".jpeg"}:
        cv2.imwrite(str(path), image, [cv2.IMWRITE_JPEG_QUALITY, 95])
    else:
        cv2.imwrite(str(path), image, [cv2.IMWRITE_PNG_COMPRESSION, 3])


def order_points(pts: np.ndarray) -> np.ndarray:
    pts = np.asarray(pts, dtype=np.float32)
    rect = np.zeros((4, 2), dtype=np.float32)

    s = pts.sum(axis=1)
    rect[0] = pts[np.argmin(s)]  # top-left
    rect[2] = pts[np.argmax(s)]  # bottom-right

    diff = np.diff(pts, axis=1)
    rect[1] = pts[np.argmin(diff)]  # top-right
    rect[3] = pts[np.argmax(diff)]  # bottom-left
    return rect


def four_point_transform(image: np.ndarray, pts: np.ndarray) -> np.ndarray:
    rect = order_points(pts)
    (tl, tr, br, bl) = rect

    width_a = np.linalg.norm(br - bl)
    width_b = np.linalg.norm(tr - tl)
    max_width = max(int(width_a), int(width_b), 1)

    height_a = np.linalg.norm(tr - br)
    height_b = np.linalg.norm(tl - bl)
    max_height = max(int(height_a), int(height_b), 1)

    dst = np.array(
        [
            [0, 0],
            [max_width - 1, 0],
            [max_width - 1, max_height - 1],
            [0, max_height - 1],
        ],
        dtype=np.float32,
    )

    M = cv2.getPerspectiveTransform(rect, dst)
    warped = cv2.warpPerspective(
        image,
        M,
        (max_width, max_height),
        flags=cv2.INTER_CUBIC,
        borderMode=cv2.BORDER_REPLICATE,
    )
    return warped


def find_contours(binary: np.ndarray):
    found = cv2.findContours(binary, cv2.RETR_LIST, cv2.CHAIN_APPROX_SIMPLE)
    return found[0] if len(found) == 2 else found[1]


def detect_document_quad(bgr: np.ndarray, min_area_ratio: float = 0.18):
    h, w = bgr.shape[:2]
    max_side = max(h, w)
    scale = 1400.0 / max_side if max_side > 1400 else 1.0

    if scale != 1.0:
        small = cv2.resize(
            bgr,
            (int(w * scale), int(h * scale)),
            interpolation=cv2.INTER_AREA,
        )
    else:
        small = bgr.copy()

    gray = cv2.cvtColor(small, cv2.COLOR_BGR2GRAY)
    gray = cv2.GaussianBlur(gray, (5, 5), 0)

    edges = cv2.Canny(gray, 50, 150)
    thresh = cv2.adaptiveThreshold(
        gray, 255, cv2.ADAPTIVE_THRESH_GAUSSIAN_C, cv2.THRESH_BINARY, 31, 15
    )
    thresh = 255 - thresh

    mask = cv2.bitwise_or(edges, thresh)
    kernel = cv2.getStructuringElement(cv2.MORPH_RECT, (9, 9))
    mask = cv2.morphologyEx(mask, cv2.MORPH_CLOSE, kernel, iterations=2)
    mask = cv2.dilate(mask, None, iterations=1)

    contours = find_contours(mask)
    contours = sorted(contours, key=cv2.contourArea, reverse=True)

    img_area = small.shape[0] * small.shape[1]
    best = None
    best_area = 0

    for cnt in contours[:30]:
        area = cv2.contourArea(cnt)
        if area < min_area_ratio * img_area:
            continue

        peri = cv2.arcLength(cnt, True)
        approx = cv2.approxPolyDP(cnt, 0.02 * peri, True)

        if len(approx) == 4 and area > best_area:
            best = approx.reshape(4, 2).astype(np.float32)
            best_area = area

    if best is None:
        return None

    return best / scale


def auto_crop_document(bgr: np.ndarray):
    quad = detect_document_quad(bgr)
    if quad is None:
        return bgr, None
    return four_point_transform(bgr, quad), quad


def stride_integral(img: np.ndarray, stride: int = 8):
    h, w = img.shape[:2]
    pad_h = (stride - (h % stride)) % stride
    pad_w = (stride - (w % stride)) % stride

    if pad_h:
        img = cv2.copyMakeBorder(img, pad_h, 0, 0, 0, borderType=cv2.BORDER_REPLICATE)
    if pad_w:
        img = cv2.copyMakeBorder(img, 0, 0, pad_w, 0, borderType=cv2.BORDER_REPLICATE)

    return img, pad_h, pad_w


def deshadow_prompt(img: np.ndarray) -> np.ndarray:
    h, w = img.shape[:2]
    resized = cv2.resize(img, (1024, 1024), interpolation=cv2.INTER_CUBIC)

    rgb_planes = cv2.split(resized)
    bg_imgs = []

    for plane in rgb_planes:
        dilated = cv2.dilate(plane, np.ones((7, 7), np.uint8))
        bg = cv2.medianBlur(dilated, 21)
        bg_imgs.append(bg)

    bg_imgs = cv2.merge(bg_imgs)
    bg_imgs = cv2.resize(bg_imgs, (w, h), interpolation=cv2.INTER_CUBIC)
    return bg_imgs


def appearance_prompt(img: np.ndarray) -> np.ndarray:
    h, w = img.shape[:2]
    resized = cv2.resize(img, (1024, 1024), interpolation=cv2.INTER_CUBIC)

    rgb_planes = cv2.split(resized)
    result_norm_planes = []

    for plane in rgb_planes:
        dilated = cv2.dilate(plane, np.ones((7, 7), np.uint8))
        bg = cv2.medianBlur(dilated, 21)
        diff = 255 - cv2.absdiff(plane, bg)
        norm = cv2.normalize(
            diff, None, alpha=0, beta=255, norm_type=cv2.NORM_MINMAX, dtype=cv2.CV_8UC1
        )
        result_norm_planes.append(norm)

    result_norm = cv2.merge(result_norm_planes)
    result_norm = cv2.resize(result_norm, (w, h), interpolation=cv2.INTER_CUBIC)
    return result_norm


def mild_tone_normalize(bgr: np.ndarray) -> np.ndarray:
    lab = cv2.cvtColor(bgr, cv2.COLOR_BGR2LAB)
    l, a, b = cv2.split(lab)

    lo = np.percentile(l, 0.5)
    hi = np.percentile(l, 99.5)

    if hi - lo > 1:
        l = np.clip((l.astype(np.float32) - lo) * 255.0 / (hi - lo), 0, 255).astype(np.uint8)

    out = cv2.merge((l, a, b))
    return cv2.cvtColor(out, cv2.COLOR_LAB2BGR)


def convert_state_dict(state_dict):
    converted = {}
    for k, v in state_dict.items():
        if k.startswith("module."):
            converted[k[7:]] = v
        else:
            converted[k] = v
    return converted


def torch_load_compat(path: str):
    try:
        return torch.load(path, map_location="cpu", weights_only=False)
    except TypeError:
        return torch.load(path, map_location="cpu")


class ScannerLikePipeline:
    def __init__(self, device: str | None = None):
        if device is None:
            device = "cuda" if torch.cuda.is_available() else "cpu"

        if device == "cuda" and not torch.cuda.is_available():
            print("CUDA requested but unavailable; falling back to CPU.", file=sys.stderr)
            device = "cpu"

        self.device = torch.device(device)
        self.use_fp16 = self.device.type == "cuda"

        if self.device.type == "cuda":
            torch.backends.cuda.matmul.allow_tf32 = True
            torch.backends.cudnn.allow_tf32 = True

        print(f"[init] device={self.device}", file=sys.stderr)

        # UVDoc
        print(f"[init] loading UVDoc: {UVDOC_MODEL_ID}", file=sys.stderr)
        self.uvdoc_processor = AutoImageProcessor.from_pretrained(UVDOC_MODEL_ID)
        self.uvdoc = AutoModel.from_pretrained(UVDOC_MODEL_ID, torch_dtype=torch.float32)
        self.uvdoc.to(self.device)
        self.uvdoc.eval()

        # DocRes
        print(f"[init] downloading DocRes weights: {DOCRES_REPO_ID}/{DOCRES_FILENAME}", file=sys.stderr)
        weights_path = hf_hub_download(repo_id=DOCRES_REPO_ID, filename=DOCRES_FILENAME)

        self.docres = restormer_arch.Restormer(
            inp_channels=6,
            out_channels=3,
            dim=48,
            num_blocks=[2, 3, 3, 4],
            num_refinement_blocks=4,
            heads=[1, 2, 4, 8],
            ffn_expansion_factor=2.66,
            bias=False,
            LayerNorm_type="WithBias",
            dual_pixel_task=True,
        )

        checkpoint = torch_load_compat(weights_path)
        state = checkpoint["model_state"] if isinstance(checkpoint, dict) and "model_state" in checkpoint else checkpoint
        self.docres.load_state_dict(convert_state_dict(state), strict=True)
        self.docres.to(self.device)
        self.docres.eval()

        if self.use_fp16:
            self.docres.half()

    def rectify_uvdoc(self, bgr: np.ndarray) -> np.ndarray:
        rgb = cv2.cvtColor(bgr, cv2.COLOR_BGR2RGB)
        pil = Image.fromarray(rgb)

        batch = self.uvdoc_processor(images=pil, return_tensors="pt")
        pixel_values = batch["pixel_values"].to(self.device, dtype=torch.float32)

        with torch.inference_mode():
            outputs = self.uvdoc(pixel_values=pixel_values)

        rectified = self.uvdoc_processor.post_process_document_rectification(
            outputs.last_hidden_state.float(),
            batch["original_images"],
        )[0]["images"]

        return np.ascontiguousarray(rectified.cpu().numpy())

    def docres_restore(self, bgr: np.ndarray, task: str) -> np.ndarray:
        if task not in {"deshadowing", "appearance"}:
            raise ValueError(f"Unsupported DocRes task: {task}")

        prompt = deshadow_prompt(bgr) if task == "deshadowing" else appearance_prompt(bgr)
        h, w = bgr.shape[:2]
        network_input = np.concatenate((bgr, prompt), axis=-1)

        max_size = 1600
        use_resize_branch = max(h, w) >= max_size

        if not use_resize_branch:
            network_input, pad_h, pad_w = stride_integral(network_input, 8)
        else:
            network_input = cv2.resize(network_input, (max_size, max_size), interpolation=cv2.INTER_CUBIC)
            pad_h = pad_w = 0

        tensor = torch.from_numpy(network_input.transpose(2, 0, 1)).unsqueeze(0).float() / 255.0
        tensor = tensor.to(self.device)

        if self.use_fp16:
            tensor = tensor.half()

        with torch.inference_mode():
            pred = self.docres(tensor)
            pred = torch.clamp(pred, 0, 1)

        pred = (pred[0].permute(1, 2, 0).float().cpu().numpy() * 255.0).astype(np.uint8)

        if not use_resize_branch:
            out = pred[pad_h:, pad_w:]
            return np.ascontiguousarray(out)

        pred[pred == 0] = 1
        shadow_map = cv2.resize(bgr, (max_size, max_size), interpolation=cv2.INTER_CUBIC).astype(np.float32)
        shadow_map = shadow_map / pred.astype(np.float32)
        shadow_map = cv2.resize(shadow_map, (w, h), interpolation=cv2.INTER_CUBIC)
        shadow_map[shadow_map == 0] = 1e-5

        out = np.clip(bgr.astype(np.float32) / shadow_map, 0, 255).astype(np.uint8)
        return out

    def process_image(self, path: Path, do_crop: bool = True, do_tone_normalize: bool = True):
        original = read_image_bgr(str(path))
        cropped, quad = auto_crop_document(original) if do_crop else (original, None)

        rectified = self.rectify_uvdoc(cropped)
        deshadowed = self.docres_restore(rectified, "deshadowing")
        enhanced = self.docres_restore(deshadowed, "appearance")
        final = mild_tone_normalize(enhanced) if do_tone_normalize else enhanced

        steps = {
            "00_original": original,
            "01_cropped": cropped,
            "02_rectified": rectified,
            "03_deshadowed": deshadowed,
            "04_enhanced": enhanced,
            "05_final": final,
        }
        return final, steps, quad


def iter_images(input_path: Path):
    exts = {".jpg", ".jpeg", ".png", ".bmp", ".tif", ".tiff", ".webp"}
    if input_path.is_file():
        return [input_path]
    return sorted([p for p in input_path.rglob("*") if p.suffix.lower() in exts])


def main():
    parser = argparse.ArgumentParser(
        description="Scanner-like document cleanup: crop -> UVDoc rectify -> DocRes deshadow -> DocRes appearance"
    )
    parser.add_argument("input", help="Input image file or directory")
    parser.add_argument("--output-dir", default="out", help="Where final images are written")
    parser.add_argument("--device", default=None, help="cuda or cpu; default: auto")
    parser.add_argument("--skip-crop", action="store_true", help="Disable OpenCV page crop")
    parser.add_argument("--no-tone-normalize", action="store_true", help="Disable final tone normalization")
    parser.add_argument("--save-steps", action="store_true", help="Save intermediate images too")
    args = parser.parse_args()

    input_path = Path(args.input)
    out_dir = Path(args.output_dir)
    out_dir.mkdir(parents=True, exist_ok=True)

    images = iter_images(input_path)
    if not images:
        raise SystemExit(f"No images found under: {input_path}")

    pipeline = ScannerLikePipeline(device=args.device)

    ok = 0
    failed = 0

    for img_path in images:
        try:
            final, steps, quad = pipeline.process_image(
                img_path,
                do_crop=not args.skip_crop,
                do_tone_normalize=not args.no_tone_normalize,
            )

            out_path = out_dir / f"{img_path.stem}_scanned.png"
            save_image(out_path, final)

            if args.save_steps:
                step_dir = out_dir / f"{img_path.stem}_steps"
                for name, image in steps.items():
                    save_image(step_dir / f"{name}.png", image)

            print(f"[ok] {img_path} -> {out_path}")
            if quad is None and not args.skip_crop:
                print(f"     crop: no document quad found, used original frame")
            ok += 1

        except Exception as e:
            print(f"[error] {img_path}: {e}", file=sys.stderr)
            failed += 1

    print(f"\nDone. ok={ok} failed={failed}")


if __name__ == "__main__":
    main()
```
