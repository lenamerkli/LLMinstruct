Is it correct that `llama-cli --version` has stopped showing cuda devices between version b8695 and b10068?
§a§
**Yes.** This appears to be an intentional change in initialization/logging behavior, not evidence that CUDA support is missing.

- Builds around **b8660–b8977** still printed GPU initialization as a side effect of `--version`.
- Later changes reduced startup logging and made device enumeration optional because enumerating CUDA devices creates a CUDA primary context. The relevant changes landed during May–June 2026.
- In b10068, `--version` is handled before the normal CLI runtime initialization, so its output is now essentially limited to build/version information.

To verify that your new build sees CUDA, use the dedicated option:

```bash
llama-cli --list-devices
```

That should produce something resembling:

```text
Available devices:
  CUDA0: NVIDIA GeForce RTX 4070 Laptop GPU (...)
```

`--list-devices` is now the documented interface for this purpose.

So the distinction is:

- **Correct:** `llama-cli --version` no longer reports CUDA devices.
- **Not implied:** CUDA support or GPU detection has been removed.

I haven't identified the exact first build number without bisecting the release tags, but the transition occurred **after b8977 and no later than b10068**.
