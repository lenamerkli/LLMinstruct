# Bestimmung von $\int_{1}^{3}(4x+2)\,\mathrm{d}x$ als Grenzwert einer Obersumme

## 1. Zerlegung des Intervalls

Das Intervall $[1,3]$ wird in $n$ gleichgroße Teilintervalle zerlegt:

$$\Delta x = \frac{3-1}{n} = \frac{2}{n}$$

Die **rechten Stützstellen** lauten:

$$x_i = 1 + \frac{2i}{n}, \qquad i = 1, 2, \ldots, n$$

## 2. Aufstellen der Obersumme $O_n$

Da $f(x)=4x+2$ **streng monoton wachsend** ist, stimmen Ober- und Untersumme für die rechte bzw. linke Stützstelle überein – wir wählen die **rechte Obersumme**:

$$O_n = \sum_{i=1}^{n} f(x_i)\cdot\Delta x = \sum_{i=1}^{n}\left(4\!\left(1+\frac{2i}{n}\right)+2\right)\cdot\frac{2}{n}$$

## 3. Vereinfachung

**Funktionswerte ausrechnen:**

$$f(x_i) = 4 + \frac{8i}{n} + 2 = 6 + \frac{8i}{n}$$

**In die Summe einsetzen:**

$$O_n = \frac{2}{n}\sum_{i=1}^{n}\left(6 + \frac{8i}{n}\right) = \frac{2}{n}\left(6\sum_{i=1}^{n}1 \;+\; \frac{8}{n}\sum_{i=1}^{n}i\right)$$

**Gegebene Summenformel einsetzen** $\left(\displaystyle\sum_{i=1}^n i = \frac{n(n+1)}{2}\right)$:

$$O_n = \frac{2}{n}\left(6n + \frac{8}{n}\cdot\frac{n(n+1)}{2}\right) = \frac{2}{n}\left(6n + 4(n+1)\right)$$

$$O_n = \frac{2}{n}\left(10n + 4\right) = 20 + \frac{8}{n}$$

## 4. Grenzwert

$$\boxed{\int_{1}^{3}(4x+2)\,\mathrm{d}x = \lim_{n\to\infty}O_n = \lim_{n\to\infty}\left(20+\frac{8}{n}\right) = 20}$$

## 5. Kontrolle (Stammfunktion)

$$\left[2x^2+2x\right]_1^3 = (18+6)-(2+2)=24-4 = 20\;\checkmark$$
