Erklären Sie in einem zusammenhängenden Text (ca. eine halbe Seite), wie ein Neuronales Netzwerk lernt. Erklären Sie dabei zunächst, wie das Lernen beim Perzeptron funktioniert. Erläutern Sie anschliessend, wie diese Lernmechanismen auf mehrschichtige Neuronale Netzwerke übertragen werden.
§a§
Ein neuronales Netzwerk lernt, indem es seine Verbindungen zwischen den künstlichen Nervenzellen (Neuronen) schrittweise anpasst. Grundlage dafür ist das Prinzip, aus Fehlern zu lernen. Beim einfachen Perzeptron, einem der ersten Modelle neuronaler Netze, erhält jedes Eingabesignal ein Gewicht. Die Eingaben werden mit ihren Gewichten multipliziert und anschließend aufsummiert. Überschreitet die Summe einen bestimmten Schwellenwert, gibt das Perzeptron ein Signal aus, andernfalls nicht. Lernen bedeutet hier, die Gewichte so zu verändern, dass die Ausgabe möglichst oft korrekt ist. Wenn das Perzeptron beispielsweise eine Eingabe falsch klassifiziert, werden die Gewichte angepasst: Gewichte von wichtigen Eingaben werden erhöht oder verringert, abhängig davon, ob die Ausgabe zu niedrig oder zu hoch war. Dieser Vorgang wird für viele Trainingsbeispiele wiederholt, bis das Perzeptron die Daten möglichst richtig einordnet.

Mehrschichtige neuronale Netzwerke erweitern dieses Prinzip, indem sie mehrere Schichten von Neuronen verwenden: eine Eingabeschicht, eine oder mehrere verborgene Schichten und eine Ausgabeschicht. Dadurch können auch komplexe Zusammenhänge gelernt werden, die ein einzelnes Perzeptron nicht erfassen kann. Das Lernen erfolgt hier mit dem sogenannten Backpropagation-Verfahren. Zunächst werden die Eingabedaten durch das Netzwerk geleitet („Forward Pass“), bis eine Ausgabe entsteht. Anschließend wird der Fehler zwischen der tatsächlichen und der gewünschten Ausgabe berechnet. Dieser Fehler wird dann rückwärts durch das Netzwerk propagiert. Dabei wird für jedes Gewicht bestimmt, wie stark es zum Fehler beigetragen hat. Die Gewichte werden danach mithilfe eines Optimierungsverfahrens, meist Gradientenabstieg, leicht verändert, sodass der Fehler kleiner wird. Durch viele Wiederholungen mit großen Datenmengen lernt das Netzwerk schrittweise, Muster zu erkennen und korrekte Vorhersagen zu treffen.
