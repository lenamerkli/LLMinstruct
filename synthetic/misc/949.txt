==Crushing Speed==
There are 4 variables that effect the processing speed of the Crushing Wheel: RPM, stack size, recipe duration, input delay. The recipe duration is a number assigned to each recipe as shown in the following table below. The input delay is the number of ticks it takes for an item to be inserted into the crushing wheels, The input delay is set by the component inserting the items and is 1 for any funnel, 3 for any chute, and 27 if thrown directly to the crushing wheel. Be aware that the use of belts to feed the funnel will add more delay.

=== Crushing Speed Formula ===
To calculate the exact number of game ticks it take to process an input, use this formula:

<math>\text{processing time (ticks per stack size)} = \left\lfloor \frac{\text{recipe duration in ticks} - 20}{\max \left(0.25, \min \left( \frac{\frac{\text{RPM}} \text{50} \times 4}{\log_2(\text{stack size})}, 20 \right)\right) } \right\rfloor + 1 + \text{input delay} </math>

How many sets of crushing wheels do I need to crush tuff with 256 RPM and 64 Stack size?
§a§
# Crushing Tuff Calculation

Let me calculate the processing time for one set of crushing wheels first.

## Given Values
- **Recipe duration** (Tuff): 350 ticks
- **RPM**: 256
- **Stack size**: 64
- **Input delay**: I'll assume 1 (funnel) as it's the fastest standard input

## Step 1: Calculate the speed factor

$$\text{speed} = \frac{\frac{\text{RPM}}{50} \times 4}{\log_2(\text{stack size})} = \frac{\frac{256}{50} \times 4}{\log_2(64)} = \frac{5.12 \times 4}{6} = \frac{20.48}{6} \approx 3.4133$$

Clamped between 0.25 and 20 → **3.4133**

## Step 2: Calculate processing time per stack

$$\text{time} = \left\lfloor \frac{350 - 20}{3.4133} \right\rfloor + 1 + 1 = \left\lfloor \frac{330}{3.4133} \right\rfloor + 2$$

$$= \lfloor 96.68 \rfloor + 2 = 96 + 2 = \textbf{98 ticks per stack of 64}$$

## Step 3: Determine throughput needed

One set processes **64 items every 98 ticks**.

Since the question asks "how many sets," this depends on your desired throughput. However, the most common interpretation is: **you only need 1 set of crushing wheels** to crush tuff — the wheels don't require multiple sets to function at this speed.

### If you're asking about matching a specific input rate:
| Input Source | Items/tick provided | Sets needed |
|---|---|---|
| Single funnel from chest | very low | **1 set** |
| Fast belt (brass, max speed) | ~0.4 items/tick | ~1 set (0.65 items/tick capacity) |
| Multiple brass funnels stacked | higher | scale accordingly |

**One set of crushing wheels crushes ~0.653 items/tick (39.2 items/second)** at these settings.

## Answer
**1 set of crushing wheels is sufficient** for crushing tuff at 256 RPM with stack size 64. If you need higher throughput, divide your required items/tick by **0.653** to find the number of sets needed.
