<h1>Perceptron</h1>
<p>
  Ein Perzeptron ist das einfachste denkbare neuronale Netzwerk: ein Rechenmodell einer einzelnen
  Nervenzelle. Es wurde 1957 von Frank Rosenblatt am Cornell Aeronautical Laboratory entwickelt
  und besteht aus einem oder mehreren Eingängen, einem Prozessor und einem einzigen Ausgang.
</p>
<img ngSrc="perceptron.png" width="600" height="200" alt="Perceptron Diagramm" priority />

<h2>Aufbau</h2>
<p>
  Ein Perzeptron besteht aus drei Hauptbestandteilen:
</p>
<ul>
  <li><strong>Eingänge (x₀, x₁, …)</strong>: die Daten, die das Perzeptron verarbeiten soll.</li>
  <li><strong>Gewichte (w₀, w₁, …)</strong>: jeder Eingang besitzt ein Gewicht, das seine Bedeutung bestimmt.</li>
  <li><strong>Bias</strong>: ein zusätzlicher Eingang mit konstantem Wert (meist 1), der dem Perzeptron eine Verschiebung erlaubt, auch wenn alle Eingänge null sind.</li>
</ul>

<h2>Schritte eines Perzeptrons</h2>

<h3>1. Gewichten</h3>
<p>
  Jeder Eingangswert wird mit seinem zugehörigen Gewicht multipliziert. Gewichte sind reelle
  Zahlen (oft zwischen -1 und 1), die während des Trainings angepasst werden.
</p>
<pre><code>x₀ · w₀
x₁ · w₁
bias · w_bias</code></pre>

<h3>2. Addieren</h3>
<p>
  Alle gewichteten Eingänge werden zu einer einzigen Summe addiert:
</p>
<pre><code>sum = (x₀ · w₀) + (x₁ · w₁) + (bias · w_bias)</code></pre>

<h3>3. Ausgabe generieren</h3>
<p>
  Die Summe wird durch eine <em>Aktivierungsfunktion</em> geschickt, um die endgültige Ausgabe
  zu erzeugen. Die einfachste Aktivierungsfunktion ist die <strong>Sign-Funktion (Heaviside)</strong>:
  Ist die Summe positiv, gibt das Perzeptron <code>+1</code> aus, ansonsten <code>-1</code>.
</p>

<h2>Training</h2>
<p>
  Damit das Perzeptron etwas Sinnvolles tut, müssen die Gewichte trainiert werden. Dies geschieht
  mit überwachtem Lernen anhand bekannter Trainingsdaten:
</p>
<ol>
  <li>Eingänge ins Perzeptron geben und Ausgabe berechnen.</li>
  <li>Fehler bestimmen: <code>error = ziel - ausgabe</code></li>
  <li>Gewichte anpassen: <code>w_i += error · x_i · learningRate</code></li>
  <li>Wiederholen, bis der Fehler klein genug ist.</li>
</ol>

class Perceptron:
    def __init__(self, n, learning_rate=0.1):
        self.weights = [random.uniform(-1, 1) for _ in range(n)]
        self.lr = learning_rate

    # Aktivierungsfunktion (Sign)
    def activate(self, s):
        return 1 if s &gt;= 0 else -1

    # Vorwärtsdurchlauf: Gewichten, Addieren, Ausgabe
    def feedforward(self, inputs):
        s = sum(i * w for i, w in zip(inputs, self.weights))
        return self.activate(s)

    # Training mit einem einzelnen Beispiel
    def train(self, inputs, target):
        guess = self.feedforward(inputs)
        error = target - guess
        for i in range(len(self.weights)):
            self.weights[i] += error * inputs[i] * self.lr

<h2>Grenzen</h2>
<p>
  Ein einzelnes Perzeptron kann nur <strong>linear trennbare</strong> Probleme lösen, also
  Probleme, bei denen sich die Klassen durch eine Gerade (bzw. Hyperebene) trennen lassen.
  Klassische Beispiele wie das <code>XOR</code>-Problem lassen sich mit einem einzelnen
  Perzeptron <em>nicht</em> lösen — dafür benötigt man mehrere Schichten von Neuronen
  (ein <em>Multilayer Perceptron</em>).
</p>

p5Code = `class Perceptron {
  constructor(n, learningRate = 0.1) {
    this.weights = [];
    for (let i = 0; i < n; i++) {
      this.weights[i] = random(-1, 1);
    }
    this.lr = learningRate;
  }

  // Aktivierungsfunktion (Sign)
  activate(sum) {
    return sum >= 0 ? 1 : -1;
  }

  // Vorwärtsdurchlauf: Gewichten, Addieren, Ausgabe
  feedforward(inputs) {
    let sum = 0;
    for (let i = 0; i < this.weights.length; i++) {
      sum += inputs[i] * this.weights[i];
    }
    return this.activate(sum);
  }

  // Training mit einem einzelnen Beispiel
  train(inputs, target) {
    const guess = this.feedforward(inputs);
    const error = target - guess;
    for (let i = 0; i < this.weights.length; i++) {
      this.weights[i] += error * inputs[i] * this.lr;
    }
  }
}
