§u§
My ETS2 game crashed. Where can I find the crash log? I am using fedora.
§a§
For Euro Truck Simulator 2 on Linux (including Fedora), the game log is stored in your user's local share directory. Look here:

```
~/.local/share/Euro Truck Simulator 2/game.log.txt
```

The full path expands to `/home/yourusername/.local/share/Euro Truck Simulator 2/game.log.txt`.

**A few tips for finding it:**

- `game.log.txt` is the main log file. It gets overwritten each time you launch the game, so grab it **right after** a crash before restarting, or copy it aside for safekeeping.
- The `.local` folder is hidden by default. In a file manager, press **Ctrl+H** to reveal hidden files/folders, or just use the terminal.
- You can quickly open it in the terminal with:
  ```
  cat ~/.local/share/"Euro Truck Simulator 2"/game.log.txt
  ```
  or open it in a text editor like:
  ```
  gnome-text-editor ~/.local/share/"Euro Truck Simulator 2"/game.log.txt
  ```

**If you're running the Windows version through Steam Proton** instead of the native Linux build, the log will instead be inside the Proton compatibility prefix, roughly at:

```
~/.local/share/Steam/steamapps/compatdata/227300/pfx/drive_c/users/steamuser/Documents/Euro Truck Simulator 2/game.log.txt
```

(`227300` is ETS2's Steam app ID.)

When you open the log, look near the bottom for lines marked with `<ERROR>` or crash/exception messages — those usually point to the cause (often a mod, a graphics/driver issue, or a corrupted file). If you'd like, paste the relevant error lines here and I can help interpret them.

### Other Issues in Your Log
- **Oversize DLC errors** (`mod_czloko.sii`, dangling pointers to `route_data.ber_szcz1`, `bre_tra1`, etc.): This usually comes from an old special transport / oversize job mod conflicting with the official *Oversize* DLC. - You have many heavy cargo / lowbed / realistic lights / rain mods. Some of them are quite old and may cause secondary problems.
