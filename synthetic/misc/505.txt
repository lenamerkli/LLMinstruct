§u§
I know how several items in a directory are called. I want to find the path to this directory. How can I do this on fedora linux?
§a§
You can do this with either **`locate` (fast, uses an index)** or **`find` (no index, slower but always accurate)**.

## Option 1: Fast (recommended) — `locate` / `plocate`
On Fedora the database-backed command is usually provided by **plocate**.

1) Install (if needed) and build the index:
```bash
sudo dnf install plocate
sudo updatedb
```

2) Search for one of the known items to get full paths:
```bash
locate -b '\yourfilename.ext'
```
(`-b` anchors the match to the basename.)

If you know multiple filenames, run locate for each, then look for a common parent directory.

---

## Option 2: Find the directory that contains *all* the known items (pure `find`)
If you know several item names that should all be in the *same* directory, this finds directories that contain them all:

```bash
find / -type d 2>/dev/null -exec sh -c '
d="$1"
[ -e "$d/file1" ] && [ -e "$d/file2" ] && [ -e "$d/file3" ] && printf "%s\n" "$d"
' sh {} \;
```

Replace `file1 file2 file3` with your real names.

Tips:
- Searching from `/` can be slow. If you can, narrow it down, e.g.:
  ```bash
  find /home /mnt -type d ...
  ```
- If you expect the “items” are files only, you can use `-f` tests:
  ```bash
  [ -f "$d/file1" ] ...
  ```

---

## Option 3: Find directories that contain N specific filenames (counting approach)
This finds directories that contain **all** of the listed filenames, by counting matches:

```bash
find / -type f \( -name 'file1' -o -name 'file2' -o -name 'file3' \) -printf '%h\n' 2>/dev/null \
| sort | uniq -c | awk '$1==3 {print $2}'
```

- Replace names and change `3` to however many filenames you listed.
